# Iris Flower Classification using KNN

## Project Overview

This project uses the K-Nearest Neighbors (KNN) Machine Learning algorithm to classify Iris flowers into:

- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Scikit-Learn
- Flask
- HTML
- CSS
- Matplotlib

## Features

- Train KNN model
- Predict flower species
- Flask web interface
- User-friendly input form

## How to Run

```bash
pip install -r requirements.txt
python app.py
```

Open:

http://127.0.0.1:5000
